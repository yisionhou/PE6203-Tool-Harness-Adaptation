## 自行设计的方法

方法名称：基于依赖关系的选择性工具知识修补（dependency-aware selective patch）。

1. 用 `(source_server, source_name)` 标识工具，比较名称、说明、输入 Schema、可选输出 Schema。对象键顺序不视为变化；新增、删除、路由、参数和说明变化分别记录路径。
2. 将知识分成工具定义与独立的规则块。每个工具卡片包含工具用法、参数约束和 Schema 形状示例；任务级工具清单依赖这些卡片。额外人工规则必须声明依赖。
3. 从变化工具出发，沿依赖图寻找需要重新生成的规则与示例；新增/删除工具同时更新工具清单。不猜测两个不同名称一定是同一个工具，改名按删除旧路由并增加新路由处理。
4. 选择性修补仅替换变化的工具记录和受影响的规则块，其余记录、规则文字保持不变并核对哈希。受影响的自由文本规则没有可执行生成配方时停止并报告待审核项，不能静默保留过时内容。
5. 全量重写使用同一生成器，重新生成目标范围内全部工具知识、规则和示例；不更新复用初始包的完整字节。三者共享同一初始知识和观察来源。
6. Schema 验证、依赖检查、示例参数验证、旧路由清理和未影响内容保留检查通过后才导出。

工具目录与规则均完全一致时，确定性全量重写和选择性修补可能生成相同的模型可见内容。这是需要如实报告的结果，不能人为制造评分差异；该情况下主要比较更新范围与实际更新耗时。
