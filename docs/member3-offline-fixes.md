# 成員三離線修正紀錄

本輪修正四項審查問題，不呼叫模型 API、不重跑付費任務。原始軌跡、提示、模型回覆、評分回執與凍結研究清單均保留。

| 問題 | 修正 | 回歸驗證 |
| --- | --- | --- |
| F1 重建報告遺失成本圖表 | 新增共用 `cost_report.py`，正式報告和繪圖使用同一成本節生成器；重建前檢查必要圖檔與量測來源指紋 | 重建兩次仍各保留一份圖表與30次量測表；缺圖或來源過期時拒絕覆寫 |
| F2 只比對結構化分數 | 每份完成回執重新解析原始回覆，再比對快取分數；只允許已記錄且可重現的缺少一個大括號恢復 | 同改兩份快取分數仍會被原文核對拒絕；低分與原文保持不變 |
| F3 依賴舊 passed 旗標 | 每次總彙整均在原有、擴充、遷移各自的正確程式根目錄重新審計 | 副本篡改環境版本，即使舊 passed=true 仍被拒絕；真實九批全部重新通過 |
| F4 接受零分 | 統計用有效分數限制為1–10；原始單次評分另要求整數 | 零分、低於1的小數、布林、非有限值等均被拒絕 |

完整離線測試：**112 passed in 41.60s**；真實 HTTP 嘗試 **0**，新增模型 API 請求 **0**。測試過程清空可用金鑰環境，並攔截真實 HTTP。

重新審計及彙整後，162條條件、TF／PE／ECS、用量、更新成本與來源指紋均與修正前一致。現有數字無須付費重跑。成本 PNG 與先前已視覺檢查的版本逐位元相同，30次量測資料沒有重測或改寫。
